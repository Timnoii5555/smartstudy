js/srs.js — self-test

This project has no build step or package manager (see js/utils.js's file header for why — it is meant to run straight from disk or a static host with zero tooling), so pulling in a Node-based runner like Vitest would mean introducing exactly the kind of build machinery the whole codebase deliberately avoids. This page is the pragmatic equivalent for this project: open it directly in a browser to verify js/srs.js's scheduling logic in isolation, the same way a unit test would, without needing Node/npm installed at all.
