ฟีเจอร์ที่ไม่มีหน้าจอเฉพาะ (cross-cutting):

•
โหมดมืด/สว่าง/ตามระบบ — ตั้งค่าได้ใน Settings, มี "zero-flash bootstrap" กันจอกระพริบตอนโหลดหน้า (js/theme.js)
•
ใช้งานได้ออฟไลน์/ไม่มีเน็ตทั้งหมด — เก็บข้อมูลใน localStorage เป็นหลัก บัญชีจริงเป็น optional layer เท่านั้น
•
สองภาษา TH/EN สลับได้ทันทีทั้งแอปโดยไม่รีเฟรช (js/i18n.js)
•
Export/นำเข้าไม่ได้อีกต่อไป (เอาออกแล้วตามคำขอผู้ใช้) — แต่ยังส่งออกเป็นรูปโปรไฟล์แบบบีบอัดเก็บใน Firestore ได้ (ไม่ใช้ Firebase Storage เพราะต้องใช้แผนเสียเงิน)
•
กระดานผู้นำข้ามผู้ใช้ (js/leaderboard.js) — sync แต้มแบบ one-way ผ่าน Firestore

3 หน้าที่แนะนำสำหรับภาพ Overview: Dashboard (รวมฟีเจอร์ engineering เยอะสุดในหน้าเดียว: อัลกอริทึมจัดตารางอ่าน + ระบบเควส/แต้ม), โหมดโฟกัส (UI ที่คัสตอมมากสุด: วงแหวน SVG jจับเวลา + เอนจิน Web Audio สร้างเสียง 6 แบบสด), ตารางเรียน (component ปฏิทินที่ซับซ้อนที่สุด เขียนเองทั้งหมดไม่ใช้ library) — ทั้งสามหน้านี้คนละแนวกัน ทำให้ภาพรวมดูมีมิติทางวิศวกรรมที่หลากหลาย ไม่ใช่แค่หน้าจอ CRUD ซ้ำๆ กัน
พรีวิวสด — โค้ดจริงรันอยู่ในกรอบมือถือ

แต่ละกรอบคือ <iframe> ที่โหลด preview-app.html (สำเนา 100% ของ index.html จริง ต่างกันแค่ 3 บรรทัดที่ระบุไว้ในไฟล์) พร้อม query ?screen=screenN — ข้อมูลตัวอย่างเป็นโปรไฟล์สมมติ "ปัญ" ที่ seed ผ่าน preview-stub.js (ดูรายละเอียดใน callout ท้ายส่วนนี้) นี่คือโค้ดจริงกำลังรันจริง ไม่ใช่ภาพวาดจำลอง

🧪
ข้อมูลสมมติ "ปัญ": วิชา TGAT · อ่านจบแล้ว 5/8 บท (63%) · แต้มสะสม 245 (เลเวล "นักอ่านฝึกหัด") · เหลือเวลาสอบ 45 วัน · โฟกัสวันนี้ 2:15 ชม. จากเป้า 4:30 ชม. — ตัวเลขทั้งหมดคำนวณจากวันที่จริง ณ ตอนที่คุณเปิดหน้านี้ (ไม่ใช่วันที่ตายตัว) ผ่านฟังก์ชันวันที่ตัวเดียวกับที่แอปจริงใช้ ดังนั้นความสัมพันธ์ของตัวเลขจะถูกต้องเสมอไม่ว่าจะเปิดวันไหน
⚠️
ข้อค้นพบจริงจากการทำพรีวิวสด (ไม่ได้แต่งขึ้น): หน้า "คลังศัพท์" (screen5) จะเริ่มที่การ์ดใบแรกเสมอ ("Aptitude") ไม่ว่าจะ seed ข้อมูลยังไง เพราะ js/flashcards.js ออกแบบมาให้ session การทบทวนไม่ถูกบันทึกลง state โดยตั้งใจ (อ่านคอมเมนต์ในไฟล์ได้) — เป็นตัวอย่างจริงว่าเทคนิค live-preview เจอพฤติกรรมจริงของโค้ดที่ภาพวาดจำลองจะไม่มีวันเจอ

8 prompts total (1 overview + 7 per-screen), all in English for pasting into an image generator. Every prompt uses the exact same "ปัญ / TGAT" sample dataset described in Tab 1 so every generated image stays consistent with the others.
